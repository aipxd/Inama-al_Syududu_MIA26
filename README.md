# CekPangan
Website untuk melihat harga pangan dan bulan yang biasanya murah atau mahal,
dengan sumber data Badan Pangan Nasional (Januari 2021 - Januari 2026). 

## Tech Stack
1. HTML
2. CSS
3. JS  
4. Vite + React.js 
5. TypeScript
6. Tailwind CSS
7. Recharts
8. data statis JSON
9. Vercel.

## Cara Menjalankan
git clone https://github.com/aipxd/Inamaal_Syududu_MIA26.git
cd Inamaal_Syududu_MIA26
npm install
npm run dev
Buka http://localhost:3000

## Progress Saat Ini
Selesai: landing page, Dashboard Cek Harga.
Dalam pengerjaan: Peringkat Provinsi, Panduan.
